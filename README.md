# RunningCoach — AI-тренер по бегу в Telegram и VK

Беговый AI-тренер, который живёт в мессенджерах: планирует неделю тренировок,
разбирает выполненные пробежки по кругам с часов, ведёт дневник питания,
читает лабораторные анализы и рисует «сторис-карточки» прогресса.
Данные берутся из [intervals.icu](https://intervals.icu) — сервиса-агрегатора
тренировок (Garmin, COROS, Suunto, Polar и др.), сайт: **https://beg-ai.ru**.

## Для кого

- Любители, готовящиеся к забегу (от 5 км до марафона), у которых нет
  живого тренера.
- Продвинутые бегуны с большими объёмами (отдельный «элитный» пайплайн
  планирования: несколько сессий в день, стиль по медиане факта).
- Все, кому нужен «тренер в кармане»: утром пришёл разбор вчерашней
  тренировки и совет на сегодня, вечером — карточка для соцсетей.

## Ключевые возможности

- **План недели через AI** — трёхстадийная генерация: тренировки → DSL-этапы
  для часов → план питания по нагрузке. Учитывает пульсовые зоны, форму
  (CTL/ATL/TSB), боли, погоду, энергобаланс.
- **Утренний разбор** — сравнение вчерашней тренировки с планом по дате,
  вердикт «выполнена / легче / тяжеле́е / пропущена», авто-корректировка
  остатка недели при необходимости.
- **Изменение тренировок диалогом** — «переставь длинный на воскресенье,
  убери интервалы» → AI предлагает план изменений, атлет подтверждает
  кнопкой «✅» — только после этого план и календарь меняются.
- **Выгрузка плана в intervals.icu** — этапы появляются на часах Garmin/COROS
  с пульсовыми и темповыми таргетами.
- **Карточки для соцсетей** — премиум PNG-карточки тренировки и недельного
  прогресса с AI-фонами (в кэше, без повторных генераций).
- **Питание** — план недели по энергобалансу (BMR + тренировки + NEAT),
  дневник еды («съел тарелку каши») с оценкой ккал/БЖУ и остатком нормы.
- **Лаборатории** — анализы крови и газоанализ (CPET) по PDF/фото: rule-флаги
  (ферритин, гемоглобин, витамин D, ТТГ…), зоны из вентиляционных порогов.
- **Чат с тренером** — свободный диалог с контекстом данных атлета.
- **PWA** — веб-интерфейс с OAuth-входом через intervals.icu.

## Как устроено

```
intervals.icu ←─(синк активностей/wellness)─→ PostgreSQL
                                                  ↑
Telegram-бот ─┐                                   │
VK-бот ───────┼─→ очередь задач (job_queue) ─→ AI-воркеры
PWA ──────────┘                                   │
                                            AI-провайдер (лестница моделей)
```

Простая и надёжная схема без брокеров и контейнеров:

| Компонент | Роль |
|---|---|
| Боты Telegram и VK | Long Poll, паритет фич: одинаковые команды, меню, FSM-диалоги |
| Очередь задач | Таблица `job_queue` в PostgreSQL, приоритеты (чат > анализ > изменения плана) |
| AI-воркеры | Обрабатывают задачи: утренний совет, план недели, анализ, питание |
| Планировщик | Ставит утренние задачи в индивидуальное время каждого атлета |
| API (FastAPI) | PWA, OAuth intervals.icu, связка «бот ↔ веб» — за nginx |
| PostgreSQL 16 | Единое хранилище: атлеты, планы, факты, зоны, история чатов |

**Стек:** Python 3.12, aiogram 3, FastAPI, psycopg3, PostgreSQL 16, nginx,
PIL (карточки), AI — Claude Sonnet (планирование), Gemini Flash (анализ/чат),
дешёвые модели — DSL и питание; резервный провайдер с автоматическим фолбэком.

## Инженерные решения, которыми гордимся

- **Инварианты плана держит код, а не промпт.** Сумма этапов DSL = дистанция
  дня, зоны на лёгких днях, «диалог не переписывает план сам» — всё
  проверяется кодом на выходе пайплайна, промпт — лишь первая линия
  (см. `docs/features/planning.md`).
- **Дедупликация и фан-аут сообщений.** Задача ставится один раз на атлета,
  а результат доставляется во ВСЕ каналы (Telegram + VK) — контракт
  «результат приходит в оба мессенджера» не может нарушиться.
- **Кэш AI-фонов карточек.** Ключ = модель + промпт + хеш фото героя;
  счётчик variety прокручивает сцены, поэтому каждое нажатие `/card`
  показывает новый вид, а не кэш-клон.
- **Честный AI.** Неоднозначная порция еды → переспрос, а не молчаливая
  запись выдуманных калорий; разбор анализов всегда завершается дисклеймером.
